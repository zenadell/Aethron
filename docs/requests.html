Every Request, Measured

Aethron rebuilt the “Build Apps People Love” screenshot as code, then took requests in plain words. A model writes each change. Aethron renders it in a real browser, measures every claim, and keeps it only when the measurements prove it. Since 15 September the Automatic General Measure (AGM) also records the whole page before and after, and every difference must be explained by the request. Every request is listed below with its verdict as of today, refused ones included.

  • 14 requests asked in plain words
  • 10 applied and passing today's checks
  • 3 refused, each for a reason worth reading
  • 1 applied earlier, refused today
  • $1.12 spent in total, under a $1.50 ceiling Aethron enforces itself

What running them found

Four faults, none of which a passing test would have shown

  • A colour nobody could see passed every check. Green was set under the button's gradient: the property said green, the button looked identical. Colour is now measured on the rendered pixels, not just the style.
  • A spinner could not be claimed at all. Every loader request was refused with “0 phrases typed letter by letter”, because the only motion claim measured typed words. There is now a claim that watches a thing move — and asks the browser what is animating, since under the clock these renders use, a spinning ring reads as motionless.
  • New words were refused for taking different room, some of it by 0.016 of a pixel.
  • A refusal that could not be reproduced. 97,300 pixels “changed” for a 20px-wider button; replaying that exact edit changed none. A difference is now checked against a second render of the same page before it may refuse anything.

Money: a ceiling that survives restarts, counted down by real bills and checked before any paid call. Free calls never touch it. You can see and change it in the studio.

How a change is kept: the model writes the code and states what will be true afterwards. Aethron measures each statement and holds it to the words asked. It uses the page like a person for anything that reacts. The AGM then requires every other difference on the page to be explained by the request. Anything that fails goes back to the model with the numbers; if it still fails, the page is left untouched.
