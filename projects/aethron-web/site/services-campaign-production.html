01

Overview

Drop a screenshot and Eye writes a real, responsive page, measured against the picture.

Screenshot to code, measured to the pixel

Most tools hand a screenshot to a model and hope. Aethron measures the picture first: colours, type, sizes and where every line sits, then checks the page it built against them.

Photos stay real pictures, never redrawn in code, and the page works on phones.

How a screenshot is built

Aethron reads the screenshot, finds the pictures, picks the typefaces by measuring them, then the model writes the page. Each draft is compared with the screenshot and the best one is kept.

Best for

Anyone with a design shot
