Aethron MCP

Use Aethron from your own coding agent.

Aethron's tools plug into the agent you already use (Claude, Codex, Gemini, Cursor, Antigravity and anything else that speaks MCP). Your agent decides what the site should say. Aethron does the delicate work and checks every page in a real browser before it calls anything finished.

STUDIO

The MCP is part of the Studio plan ($49 a month). It runs from the Aethron app on your own Mac, signed in with your Studio account. During the beta it is open to everyone. See plans

What your agent can do with it

Every step goes through Aethron's guarded pipeline, so an agent cannot break a template by editing files by hand.

MIGRATE

Own any template

Pull a Framer or Webflow template (or any site) from its link, rewrite every word, image and link for your brand, and keep every animation.

CHECK

Proof, not promises

Builds are checked file by file and then opened in a real browser. A page that renders blank or shows a broken image fails, by name.

FIX & SHIP

Heal, port, hand over

Heal edits that did not land, port the site to Astro, Next or Vite, rebuild a page from a screenshot, and serve a preview.

Before you start

  • Install Aethron in your Applications folder. Download it here. The MCP is the app itself; there is nothing else to install.
  • Open it once and sign in with your Studio account, so this Mac knows your plan.
  • No AI key is needed for migrations. Your agent writes the copy itself. Only a few tools (rebuilding a page from a screenshot, changing a page in plain words) use the AI provider you saved in the Aethron app.
  • Your projects stay on your Mac. The agent and the Aethron app share the same projects, so anything your agent builds shows up in the app, and the other way round.

Connect your agent

Every agent starts the same command: /Applications/Aethron.app/Contents/MacOS/Aethron --mcp. Pick yours below. Menu names can move between versions of each app; the setting is always "MCP servers".

  1. Run this once in Terminal. --scope user makes Aethron available in every project.
  2. Start Claude Code and type /mcp: aethron should show as connected.
claude mcp add aethron --scope user -- /Applications/Aethron.app/Contents/MacOS/Aethron --mcp
Long steps (downloading a template, building) can take a few minutes. If a call times out, start Claude Code with MCP_TOOL_TIMEOUT=600000 claude.
  1. Open Claude → Settings → Developer → Edit Config.
  2. Add the aethron entry below inside mcpServers, save, and restart Claude.

~/Library/Application Support/Claude/claude_desktop_config.json

{
  "mcpServers": {
    "aethron": {
      "command": "/Applications/Aethron.app/Contents/MacOS/Aethron",
      "args": ["--mcp"]
    }
  }
}
  1. Add it with one command, or paste the block into your Codex config.
  2. Run codex and type /mcp to see Aethron's tools.
codex mcp add aethron -- /Applications/Aethron.app/Contents/MacOS/Aethron --mcp

Your first migration

You can simply tell your agent: "Use Aethron to migrate https://yourtemplate.framer.website for my studio, Northwind. We design kitchens in Lisbon." This is the path it will take.

  1. create_project

    Takes the template's link (or an exported file) and reads every page.

  2. fetch → inventory

    Downloads everything the site needs to run on its own, then lists every line of text, image and link.

  3. set_plan

    Your brand, tone, contact details and anything to keep or remove. learn_brand can read your current site so the copy uses your real facts.

  4. get_content → set_content_bulk

    Your agent reads 40 lines at a time and writes the new copy. Aethron refuses a line that would not fit or would break the page, and says why.

  5. build → verify → probe

    Builds the site, checks the files, then opens every page in a real browser. If something fails, heal fixes what it safely can.

  6. serve_preview

    Hands you a link to look at. The finished site is a folder you can host anywhere, or port with convert_framework.

Rules your agent follows

Aethron enforces these itself. They are here so you know why your agent sometimes takes the longer road.

  • Never hand-edit the project's files. Template pages are rebuilt by their own code when they load, so a hand edit disappears or breaks the page. Every change goes through the tools.
  • A refusal is information. When Aethron rejects a line (too long for its slot, a character that would break code), it says why. Your agent shortens it and sends it again.
  • The checks decide when it is done, not the agent. A site is finished when verify and probe pass, and their FAIL lines are reported word for word.
  • Nothing is lost. Every change keeps a snapshot, and undo keeps what it replaced.

Troubleshooting

My agent does not see any Aethron tools

Check the path: Aethron must be in /Applications. Restart the agent after changing its config, and use its MCP list (/mcp in Claude Code, Codex and Gemini CLI) to see the error.

"Aethron's MCP is part of the Studio plan"

Open the Aethron app and sign in with your Studio account. If you upgraded recently, opening the app while online confirms the new plan; then ask your agent to try again.

A step times out

Downloading a large template or building it can take a few minutes. Raise your agent's tool timeout to 10 minutes (see your agent's tab above), then ask it to run the step again.

macOS says it cannot check Aethron

Open the app once from Finder first. If macOS blocks it, go to System Settings → Privacy & Security and click Open Anyway. After that, agents can start it.

Where are my projects?

In Aethron's data folder on your Mac (~/Library/Application Support/Aethron), the same place the app uses. Ask your agent to run list_projects.

Something broke and the checks do not say why

Ask your agent to run probe on the project and paste its FAIL lines to us at aethron.jomiez.com/start. A person replies within one business day.
